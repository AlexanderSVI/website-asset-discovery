# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by emailing [alex.svist@yahoo.com](mailto:alex.svist@yahoo.com). Do not report security vulnerabilities in a public issue.

Include the WAD version, the affected component, a description of the potential impact, and steps to reproduce the issue when it is safe to do so. Do not include credentials, personal information, customer data, or other sensitive material in your report.

Do not test a suspected issue against a third-party website or service without its owner's authorization. A local test fixture is preferred when it can demonstrate the issue safely.

This contact is for vulnerability reports. For general questions or suggestions, use the contact information in `README.md`.
